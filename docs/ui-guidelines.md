# UI Guidelines

## Principles
- Keep the existing visual language. Avoid unnecessary redesigns.
- Prefer clarity and consistency over novelty.
- Maintain spacing rhythm and alignment across sections.

## Detail Sheet
- Keep metadata rows compact and aligned.
- Dropdowns and controls should follow the same radius, height, and spacing rules.
- If a control changes style, update all sibling controls to match.

## Typography
- Use existing fonts and sizes.
- Labels and values should be visually grouped, not separated by large gaps.
